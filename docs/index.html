SNAP never lets it talk.

Somewhere in your stack there's a prompt asking for JSON, a parser that mostly works, a retry loop for when it doesn't, and a token bill for thousands of generated words you immediately throw away. All of it exists for one reason: the only way to interrogate a chat model is to let it talk.

prompt → generate prose → parse JSON → validate → retry → bill
prompt → one decode → distribution

Logits in, distributions out.

The output surface is a fixed alphabet of letters. Structured by construction: there is nothing downstream to parse, validate, or repair. All questions in a request share the same state prefix, evaluated once; on full-attention models the question suffixes decode in a single batched call. With layout: question_first the question head itself stays resident in KV across requests — repeat workloads decode only the state.

1

Compile

Each question (noul, choice, score, numeric) becomes a prompt whose first answer token must be a letter.

2

Read one position

snap takes the logits at that single token position. One llama_decode per question, batched across parallel KV sequences.

3

Softmax

Letter variants pool and normalize into a distribution over your options, calibrated after snap calibrate.

ABCDEFGHIJKLMNOPQRSTUVWXYZ

The entire output surface. Past 26 options, each candidate gets its own yes/no probe batched over the shared prefix (up to 256).

Measured, not promised.

Drop-in Jev.

The wire format is Jev: point an existing client at a local snap serve and it works. Same request, same response shape.

Snap extensions are optional fields a Jev client can ignore; defaults preserve Jev semantics. Answers carry extras (status, confidence, full probabilities, coverage) on top of the Jev shape.

"type": "numeric" → distribution over {min, max, granularity}
allow_abstain → adds an __abstain__ slot, status "abstained"
"mode" → "shared" (prefix amortized) or "direct"
"layout" → "auto" | state_first | question_first | header
coverage → per-answer: mass on the allowed letters pre-renorm

snap is an independent implementation. Jev itself is a hosted model in early access. Shape of the response shown; values illustrative.
